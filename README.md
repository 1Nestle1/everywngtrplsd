# The Colonist Was Replaced

Веб‑игра в духе *The Farmer Was Replaced*. Вы управляете дроном на астероиде только кодом на языке, похожем на Python. Дрон собирает ресурсы, а ресурсы тратятся на навыки в древе навыков, которые открывают новые команды и конструкции языка. Сейчас это играбельный тестовый срез со всеми ключевыми механиками оригинала, но тема «колония на астероиде» выбрана временно.

Рядом лежат технические прототипы, на которых проверялась производительность:
- анализ вариантов (веб, Tauri или нативный движок; свой язык, JS, Python или Lua) с замерами: [docs/TECH-OPTIONS.md](docs/TECH-OPTIONS.md);
- 3D в браузере, замеры FPS и оптимизации: [docs/3D-PERFORMANCE.md](docs/3D-PERFORMANCE.md).

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev        # игра: http://localhost:5173, демо: /demo-2d.html и /3d.html
npm run dev:lan    # то же, но доступно с других устройств в Wi‑Fi (см. ниже)
npm run bench      # бенчмарк VM в терминале
npm run bench:3d   # FPS 3D-сцены в настоящем Chrome/Edge без окна
npm run build      # проверка типов + сборка в dist/
npm run test:game    # проверки языка и механик без браузера
npm run test:browser # открывает игру в Chrome/Edge без окна, сохраняет скриншоты в shots/
```

## Игра

Откройте http://localhost:5173. Прогресс и код сохраняются в `localStorage` браузера.

**Как играть.** В окне `main` нажмите «Запуск» (или Ctrl+Enter): дрон выполнит `harvest()` и соберёт мох. Циклов в начале нет, их нужно изучить в древе навыков (кнопка «Навыки» внизу или клавиша T). Внизу слева всегда видна ближайшая цель: какой навык изучить, сколько ресурсов уже есть и кнопка «Пример» с кодом для этого шага. В «Справке» есть учебник по языку, список функций и растений; закрытое там помечено, и сказано, какой навык это открывает.

**Что есть (как в оригинале):**
- свой интерпретатор Python‑подобного языка: `if/elif/else`, `while`, `for … in range()`, `def/return`, `global`, списки, кортежи, словари, методы `append/pop/…`, `import` и `from … import *` между файлами, понятные ошибки на русском с номером строки;
- конструкции языка открываются навыками: «Циклы», «Сенсоры» (if и сравнения), «Переменные», «Функции», «Списки»;
- у каждого действия есть цена в тиках, поэтому дрон тратит игровое время. Бесконечный цикл не вешает вкладку;
- несколько файлов кода в перетаскиваемых окнах, редактор CodeMirror с подсветкой Python и автодополнением открытых функций. Исполняемая строка подсвечивается, есть пошаговое выполнение («Шаг»);
- древо из 19 навыков в трёх ветках (Код, Растения, Колония) с картой связей и карточкой навыка: что он открывает в коде, цена, пример. Расширение поля 1→3→4→6→8→10, скорость до ×6, урожайность мха, осколков и спор;
- подсказки для кода: цель с прогрессом и примером, разовые советы при типичных ошибках (незрелый урожай, посадка не на ту почву, отступы), пояснения при наведении на слово в коде, учебник с примерами, которые можно скопировать или вставить в редактор;
- растения с механиками оригинала:
  - мох — аналог травы;
  - осколок — аналог куста;
  - столп — аналог дерева, не любит соседей;
  - грибница — аналог моркови, растёт на пыли после `till()`;
  - жеода — аналог тыквы: созревшие могут треснуть, а квадрат k×k сливается в гигантскую жеоду и даёт k³;
  - солнечник — аналог подсолнуха: `measure()` показывает лепестки, а энергия ускоряет дрона ×2;
  - призма — аналог кактуса: сортировка через `swap()`, отсортированная группа даёт n²;
- полив (`use_item(Items.Water)`, рост до ×5);
- лабиринт с сокровищем: `use_item(Items.Nanites, n)` на осколке, затем `can_move()` и `measure()`;
- поле закольцовано по краям. Есть `print` с облачком над дроном и `do_a_flip()`;
- финал: навык «Маяк колонии» показывает экран победы;
- 3D‑сцена на Three.js: low‑poly растения строятся кодом, дрон летает плавно, гигантские жеоды и стены лабиринта видны на поле, всплывают цифры добычи.

**Для быстрого теста:** меню справа вверху → «Песочница: изучить всё». Эта кнопка изучает все навыки, кроме финального, и выдаёт много ресурсов. Там же есть «Сбросить прогресс».

**Чего нет по сравнению с оригиналом:** нескольких дронов (`spawn_drone`), динозавров, поликультуры, удобрений, таблиц рекордов, звука и настроек.

### Открыть с телефона или другого устройства в той же Wi‑Fi

```bash
npm run dev:lan    # Vite слушает все сетевые интерфейсы на порту 5173
```

В терминале появятся строки `Network: http://…:5173/`. Нужен адрес домашней сети, обычно `192.168.x.x`. Адреса `172.x` принадлежат WSL или Docker, а `26.x` — VPN вроде Radmin, с телефона они не откроются. Пример: `http://192.168.0.132:5173/3d.html` для 3D и `http://192.168.0.132:5173/` для 2D. На телефоне камера вращается одним пальцем, приближается щипком.

Если страница не открывается:
- при первом запуске Windows спрашивает, разрешить ли Node.js доступ к сети. Нужно поставить галочку «Частные сети». Если окно уже закрыли, разрешите `node.exe` в «Брандмауэр Защитника Windows → Разрешение взаимодействия с приложением»;
- профиль Wi‑Fi в Windows должен быть «Частная сеть», а не «Общедоступная»;
- в некоторых роутерах включена «изоляция клиентов» (часто в гостевой сети), тогда устройства не видят друг друга.

Режим разработки не защищён паролем, поэтому запускайте его только в своей домашней сети.

`npm run bench:3d` ищет Chrome или Edge в стандартных местах. Другой браузер можно указать через переменную `CHROME_PATH`, размер холста — через `BENCH_WIDTH` и `BENCH_HEIGHT` (по умолчанию 1600×900).

**2D‑демо (`demo-2d.html`):** поле, по которому ходят дроны. Ими управляет байткод, который исполняется в собственной VM. Можно менять число дронов (до 20 000) и скорость действий, а также запустить бенчмарк VM прямо в браузере.

**3D‑демо (`3d.html`):** та же симуляция на Three.js. Плитки поля, растущие кристаллы‑ресурсы, летающие дроны, тени, камера вращается мышью. Можно менять размер поля (до 256×256), число дронов, скорость и включать тени. Счётчики показывают FPS, время симуляции и рендера, draw calls и число треугольников. Ссылка «Автобенчмарк» (`3d.html?bench=1`) прогоняет набор сценариев.

## Структура

Игра (`src/game/`):
- `lang/parser.ts` — лексер с отступами и парсер в AST, отмечает, какие конструкции языка использованы;
- `lang/interp.ts` — интерпретатор на генераторах: уступает управление на каждой инструкции и на каждом вызове функции дрона;
- `api.ts` — справочник: предметы, растения, навыки (ветки, места в древе, цены, примеры), функции дрона;
- `world.ts` — модель мира: рост, урожай, жеоды, призмы, лабиринт, сохранение;
- `runner.ts` — исполняет программу по бюджету тиков и связывает язык с миром;
- `render.ts` — 3D‑сцена на Three.js;
- `editor.ts` — редактор на CodeMirror 6;
- `tree.ts` — древо навыков: карта, связи, карточка навыка;
- `guide.ts` — цели по шагам, уроки, разовые советы, пояснения ключевых слов;
- `icons.ts`, `dom.ts` — SVG-иконки и помощники для DOM;
- `main.ts`, `style.css` — окна, цель и советы, справка, игровой цикл.

Проверки: `bench/game-test.ts` (без браузера: язык, механики, древо, цепочка подсказок) и `bench/game-shot.ts` (Chrome через puppeteer-core: запуск, подсказка при наведении, древо по клавише T, покупка навыка, песочница, лабиринт).

Технические прототипы:
- `src/vm.ts` — стековая VM с лимитом инструкций на порцию и ассемблер с метками.
- `src/sim.ts` — симуляция мира (поле, рост, дроны с VM), общая для 2D и 3D.
- `src/main.ts` — 2D‑демо на Canvas.
- `src/main3d.ts` — 3D‑демо на Three.js (инстансинг, рост в шейдере, автобенчмарк).
- `src/bench.ts` — сравнение скорости нативного JS и VM.
- `bench/vm-bench.ts` — запуск бенчмарка VM из Node.
- `bench/gpu-bench.ts` — запуск 3D‑бенчмарка в Chrome через puppeteer-core.
